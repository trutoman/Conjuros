# Quickstart: Redesigned Item Card Layout

## Prerequisites

- Node.js 20 or a compatible local runtime
- Dependencies installed via `npm install`
- The application running locally with `npm run dev`

## Validation Scenarios

1. Open the collection view and confirm that each item renders in a compact two-row layout.
2. Verify that spells and web links use distinct visual treatment in the item header and that the item title remains prominent.
3. Confirm that the tag row stays on a single line with overflow behavior when many tags are present.
4. Check that copy, edit, delete, and reorder controls are aligned on the right side of the card and remain keyboard accessible.
5. Switch between light and dark appearance modes and verify that the card styling remains readable in both themes.
6. Trigger a copy action and confirm that the UI shows a visible success or failure message.

## Expected Result

The collection view should feel visually tighter, easier to scan, and more consistent without changing the existing item data or ownership behavior.
